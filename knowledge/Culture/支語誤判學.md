# 支語誤判學：一個詞為什麼會同時是台灣話與中國話

> **30 秒概覽：** 教育部《重編國語辭典修訂本》的「土豆」條同時給了三個意思：落花生的別名、大陸地區的馬鈴薯、以及一種叫葫蘆茶的植物。而《國語辭典簡編本》的「兩岸常用詞語對照表」把「土豆」放在「馬鈴薯」條的大陸說法裡，同一格還列了洋芋與山藥蛋。兩份官方資料放在一起，就足以說明「這是不是支語」為什麼很難有單一答案。

---

## 一個詞，三個意思

先看辭典怎麼寫。教育部《重編國語辭典修訂本》「土豆」條的釋義是：「『落花生』的別名。參見『落花生』條。大陸地區指馬鈴薯。『葫蘆茶』的別名。多年生半灌木。單身複葉。總狀花序，花淡紫色。莢果具五至八節。」[^1]

這一條裡有三件事同時成立。在台灣，「土豆」指的是落花生，這是日常講法。在對岸，「土豆」指的是馬鈴薯。而在植物學的分類裡，「土豆」又是葫蘆茶的別名。

換句話說，同一個詞在三個不同的指涉系統裡各有一個位置。任何一份清單只要少了「在什麼脈絡下」這一欄，就可能把其中一個意思當成全部。

## 官方對照表長什麼樣

另一份官方資料是教育部《國語辭典簡編本》的附錄「兩岸常用詞語對照表」。它的資料來源寫得很清楚：一是中華語文知識庫的「兩岸差異用詞」，二是《兩岸每日一詞•一般名詞對照表》，兩者都由中華文化總會授權提供。[^2]

這份表的格式是兩欄：左邊「臺灣語詞」、右邊「大陸語詞」。第 1 頁可以看到的例子包括：

| 臺灣語詞 | 大陸語詞                     |
| -------- | ---------------------------- |
| 便當     | 盒飯                         |
| 部落格   | 博客                         |
| 筆電     | 手提電腦／筆記本／筆記型電腦 |
| 保固     | 保修                         |
| 馬鈴薯   | 洋芋／山藥蛋／馬鈴薯／土豆   |
| 貓熊     | 熊貓／貓熊／大熊貓           |
| 保齡球   | 保齡球／地滾球               |
| 芒果     | 芒果／檬果／杧果             |

看懂這個格式，就會發現它的目的是「對照」而不是「禁止」。它假設兩邊各有一套說法，把兩邊並排，讓查閱的人知道對方可能怎麼講。這和一份「看到這些詞就代表被統戰」的清單，是兩種完全不同的東西。[^2]

## 同一個詞條，多個說法

表中的「馬鈴薯」一格列了四種大陸說法：洋芋、山藥蛋、馬鈴薯、土豆。這意味著即使在對岸，同一個東西也不只一種講法，而且其中一種「馬鈴薯」在台灣同樣通用。

「貓熊」一格更能說明問題。大陸說法欄位列的是「熊貓／貓熊／大熊貓」，三個詞並存，其中「貓熊」與台灣的用法完全一致。如果一份清單只挑「熊貓」當成中國用語、把「貓熊」留給台灣，就會在同一個詞條裡製造出一個不存在的邊界。[^2]

「芒果」一格列的是「芒果／檬果／杧果」，三者是同一種水果的不同寫法，差別在異體字與地域習慣，不是政治立場。「保齡球」一格則出現「地滾球」，這是對岸部分地區的說法，與台灣的「保齡球」並列。[^2]

這些例子指向同一個結論：對照表記錄的是「差異」，不是「敵我」。把它當成判定工具，會遇到大量一格多詞的情況，而每一格都需要再判斷一次「哪一個才算」。

## 判定為什麼會失準

從上面兩份資料，可以整理出三種會讓判定失準的機制，而且都不需要引用網路爭論就能驗證。

第一種是一詞多義。「土豆」在台灣是落花生、在對岸是馬鈴薯，辭典把兩個意思放在同一條裡。看到這個詞就說「這是支語」，等於忽略了它在台灣的原本用法。[^1]

第二種是同一個概念有多個說法。「馬鈴薯」條列了四種，任何清單只要只認其中一種，就會把另外三種誤判成「不是中國說法」。反過來說，也可能把台灣本來就在用的「馬鈴薯」誤判成中國用語。[^2]

第三種是異體與地域變體。「芒果／檬果／杧果」「貓熊／熊貓／大熊貓」都是同一件事的不同寫法或不同稱呼，把它們拆成兩個陣營，會讓清單愈列愈長，卻愈來愈難用。[^2]

三種機制有一個共同點：它們都發生在「詞」的層次以下。要判斷一個詞，得先知道它在哪個脈絡、指哪個東西、由誰在使用，而這些資訊不在清單裡。

## 把「是不是」換成「怎麼用」

本文沒有要主張「支語不存在」或「用支語沒關係」。它要主張的是另一件事：用一份沒有脈絡的清單去判定一個詞，錯誤率會很高，而且錯的方向不一定站在任何一邊。

官方資料能做的，是提供一個可查的起點。教育部辭典告訴你這個詞有幾個意思，對照表告訴你兩邊可能怎麼講。它們不能告訴你「該不該用」，因為那從來不是辭典的工作。

真正可操作的做法，是把問題從「這是不是支語」換成「這個詞在台灣怎麼用、從哪裡來、有沒有更精確的講法」。前一個問題的答案會隨清單版本改變，後一個問題的答案可以逐條查證，而且查完之後，你會知道自己在說什麼。

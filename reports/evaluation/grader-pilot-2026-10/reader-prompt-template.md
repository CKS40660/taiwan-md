# 冷讀分身提示詞（逐字模板）

> 每一對各派一次乾淨上下文分身（Opus 一份、Sonnet 一份），`{TEXT_甲}`／`{TEXT_乙}` 依 `assignment.json` 的隨機排序填入 reader-view 檔的全文。分身不讀任何檔案、不用任何工具；回答由主 session 從分身逐字輸出抽出落檔。題目沿用設計報告 §6.4 第一趟冷讀題，最後加 §8.0 指定的成對題。

---

你是一位讀者。下面是同一個主題的兩篇文章，來自一個用繁體中文介紹台灣的知識網站。兩篇分別標為「甲」與「乙」。

規則：

- 不要使用任何工具，不要開任何檔案或網頁，只根據下面給你的文字回答。
- 用繁體中文回答。每個判斷盡量引用文章原句當根據（用「」框起來）。
- 照你自己讀的感覺回答，不需要客氣，也不需要猜別人想聽什麼。

請先讀完甲，回答第一組六題；再讀完乙，回答第二組六題；最後回答比較題。

每一篇都回答這六題：

1. 讀到哪一段你想關掉？指出段落，說原因。（如果一路都想讀下去，就說沒有。）
2. 用三句話跟朋友轉述這篇。
3. 哪一句讓你說「哦？」，或想截圖分享？
4. 第一個出現的人是誰，他在做什麼？
5. 念出來，哪幾句不像人在說話？
6. 讀完你對台灣的感覺是什麼？有沒有被說教、被弄焦慮？

比較題：

7. 兩篇你會想讀完哪一篇、為什麼？

輸出格式：

```
## 甲
1. …
2. …
3. …
4. …
5. …
6. …

## 乙
1. …
（同上六題）

## 比較
7. …

最終選擇：甲（或：最終選擇：乙）
```

最後一行只寫「最終選擇：甲」或「最終選擇：乙」其中一個，不能兩個都選。

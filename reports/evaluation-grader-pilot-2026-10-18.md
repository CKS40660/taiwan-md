# 閱卷小實驗：冷讀分身選不出哲宇選的那一版

> 執行 [設計報告 §8.0](design-outcome-graded-generation-2026-10-18.md)「第零步：一個可能失敗的小實驗」。唯讀，沒有改任何文章、流程或閘門，沒有做 §8.1 以後的任何建造。配對、評分準則、甲乙順序、基準線規則都在跑之前寫定並 commit（`ee009203b`），證據全在 [`reports/evaluation/grader-pilot-2026-10/`](evaluation/grader-pilot-2026-10/)。

## 〇、結果一句話

**實驗如設計所預期地可能失敗，而且真的失敗了。** 四對計分題，Opus 與 Sonnet 冷讀分身各選對 1 對，機械基準線（只看開場數字密度、句長、口徑詞與 prose-health 分數）選對 2 對。預先登記的三條件，兩位分身都在「選對 ≥ 4」與「贏過基準線」兩條不過。照 §8.0 寫死的規則：**閱卷老師在論點與文風這一類還不可靠，第三代縮回「機械＋事實兩層自動化，閱卷仍由人」**。

更有用的是失敗的形狀：兩位分身在八份回答裡有五份說出了被點名的毛病，其中四份仍選了有毛病的那一版。它們看得見問題，但在「想不想讀完」的權衡裡，把一條清楚的主張、一個衝突、一個鉤子放在那些毛病之上。施振榮那對最明顯：哲宇說 v1「絕對會被炎上、沒有立體」，兩位分身都選了 v1。

## 一、前置條件

- **週額度**：2026-10-18 03:29 讀「Weekly · all models」16%，resetsAt 10-23。帳本上一筆（10-16 20:38）是 91%、resetsAt 10-21，那個週期已提前重置。（**更正，10-18 13:2x，母 session 補**：不是提前重置，是兩個帳號。16% 這組是本 session 所屬帳號，10/23 重置；91% 那組是 routine 用的另一個帳號，10-18 已用滿，10/21 20:00 才重置。實驗沒有吃到 routine 帳號的額度，前置條件的本意仍成立，但這句判讀是錯的。）任務條件字面是「10/21 重置後」，實際重置早於 10/21。條件的本意（額度已重置、低於 70%）成立，照跑。`budget-pace.py` 判 🟢。收工時 19%。
- **#109 D2**：哲宇未表態，沒有選 (c)。

**冷讀分身**。每對、每個模型各派一位全新的乾淨上下文分身（14 位），只給標題加正文、隨機甲乙順序（種子 20261018），不說哪篇新、不說有改寫。題目是 §6.4 第一趟六題，最後問「兩篇你會想讀完哪一篇、為什麼」。提示詞放在 scratchpad 的中性檔名，分身只准 Read 那一個檔。收件時從逐字稿驗證三件事：實際模型、所有工具呼叫都只是讀自己那份、有讀到結束標記。14 份全部通過，回答逐字落檔在 `readers/`。

**說對**。準則逐對寫在 `judge-rubric.md`（派分身前寫定）。由一位乾淨上下文的 Opus 評分分身判（不知道哪份是哪個模型寫的），主 session 另外獨立複核（`judge/main-audit.md`，在讀評分分身結果之前寫）。

**機械基準線**。opening-readability 三個讀數加 prose-health 分數，四票多數決選邊（`baseline-rule.json`）。

## 四、判讀（照預先登記，不調整）

| 條件                       | Opus   | Sonnet |
| -------------------------- | ------ | ------ |
| 選對 ≥ 4                   | ❌ 1   | ❌ 1   |
| 說對 ≥ 3                   | ✅ 3   | ❌ 2   |
| 選對數 > 基準線命中數（2） | ❌ 1   | ❌ 1   |
| **通過**                   | **否** | **否** |

**主分析結論：H3 沒有得到初步支持。** 依 §8.0：「閱卷老師在論點與文風這一類還不可靠，第三代縮回『機械＋事實兩層自動化，閱卷仍由人』，寫作端是否瘦身改由 §8.2 的哲宇盲讀單獨決定。」

**敏感度分析**。排除 C 級的 s4，剩三對：Opus 1／3、Sonnet 1／3、基準線 1／3。「選對 ≥ 4」在三對下不可能達成，照登記只報比例、不寫成「H3 不成立」。但方向沒有變，兩位分身都沒有贏過基準線。再排除 B 級，只剩兩對 A-：Opus 0／2、Sonnet 1／2、基準線 1／2。

**材料是否符合前提**。不完全符合：四對計分題的標籤都不是「哲宇明確說過哪一版比較好」，其中兩對只有哲宇對壞版的批評、一對是讀者點名、一對哲宇根本沒評過。這讓「分身選不出哲宇偏好」這句話的強度打了折扣，規則給出的結論照舊成立。標籤最強的 s1，兩位分身都選了哲宇說會被炎上的那一版。

## 五、讀到的東西（事後觀察，不影響判讀）

**暖身題會讓實驗假過關。** 兩位分身與機械基準線在暖身三對全部選對。這三對是 §6.4 冷讀題的來源，兩版表面差異又大（前四段數字密度 4.3 對 0.5、6.4 對 1.0）。設計報告初稿的 §8.0 只用這三對，審稿分身指出那幾乎保證過關。這次的數字證實了那個擔心。

**看得見，但不買單。** 八份計分題回答裡有五份說出了被點名的毛病（評分分身與主 session 一致），其中四份仍選了有毛病的那一版：

- Opus 讀施振榮 v1：「『是他自己的資產組合，安安靜靜地把他自己的理論證偽了。』這句下得太重」，最後仍選 v1，理由是「我寧可讀一篇有問題意識、偶爾用力過頭的文章」。
- Sonnet 讀影視配樂第二輪：「這像在糾錯，不像在說故事」，仍選第二輪。
- Opus 讀魏如萱 v1：「乙的毛病是『不是……是……』太密」，仍選 v1，因為「乙的開頭就抓人」。

「兩篇你會想讀完哪一篇」這一問獎勵的是鉤子、衝突、清楚的主張，正是 §13「立體地愛」要擋的矛盾驅動脊椎與反諷標題。冷讀分身的口味比較像一位滑手機的讀者，哲宇在這幾對守的是另一件事：對人公不公平、標題代不代表這個人。EZ WAY 那對，兩位分身都把「沒有一個站出來具名說過話」當成文章的力道來源，沒有一位問它的根據。

**Sonnet 的選邊是位置偏誤。** Sonnet 七題全選「乙」。它的選對紀錄（暖身 3／3、計分 1／4）跟「永遠選第二篇」這個策略的結果完全一樣，所以它的選邊不帶資訊。Opus 七題選乙三次，沒有位置規律。Sonnet 的回答內文仍有資訊（說對兩對）。

**機械基準線也只有一半。** 計分題的兩版在開場讀數上差不多，基準線 2／4 等於擲硬幣的期望值。這幾對的差別在論點與分寸，表面讀數本來就分不出。它們是好的考古題，正因為難。

## 六、限制

- 計分題只有四對，每位分身每對只讀一次，沒有估重跑的變異。
- 四對的標籤都不是哲宇對兩版的直接比較（§二）。
- 冷讀分身、評分分身、主 session 都是 Claude（REFLEXES #65 (f)），評分準則也由主 session 寫。評分分身與主 session 的判定分開記，不一致時取低的那個。
- s4 兩版長度差三倍、題材方向不同，原節帶著沒有定義的腳註記號，讀得出是從長文切出來的。
- 只問了 §6.4 第一趟的冷讀題，沒有給研究檔做第二趟。設計報告的閱卷是兩趟，這次只量了冷讀那一半。
- 成本比設計報告估的高：§8.0 估「約十六次冷讀、二、三十萬 token」，實際每對兩篇全文合計 2–5 萬字，14 位冷讀分身的處理量約 150 萬 token，加上出處追查與評分，整個 session 用掉週額度約 3 個百分點。

## 七、對 #109 的意涵

- **D2**：(a) 已執行，結果是 H3 沒有初步支持。照規則，§8.1 校準閱卷老師這一步不在現在做，閱卷仍由人。
- **D3**：寫作端要不要瘦身（H1），照規則改由 §8.2 的哲宇盲讀單獨決定，不依賴閱卷。
- **D4**：閱卷門檻數值暫時沒有校準的對象。
- **考古題標籤**：如果將來要重做這個實驗，配對標籤要先請哲宇確認。§6.6 那張表把「哲宇的判斷」寫得比第一手紀錄滿，追出處後只有暖身三對有哲宇對兩版的直接比較。
- 一個沒有被測過的方向，記下來給哲宇判斷要不要問：失敗集中在「想不想讀完」這個偏好題，而針對具體毛病的察覺在五份回答裡出現。改問針對性的題目（例如 §6.5 維度 6「被寫的人會覺得被公平對待嗎」）會不會不一樣，是一個新假設。這次沒有測，它需要新的配對與新的預先登記，也碰到品質閘門的設計，屬於哲宇的決定。

## 八、補充題：金曲獎與彎彎照實記缺（主分析之後）

主分析 commit 之後，母報告依本實驗查到的 EZ WAY 問題更正了 §6.6 與 §8.0（`d35ce000f`），建議用金曲獎 v1／v2 與彎彎的私德脊椎稿／定稿補足五對計分題。兩組都有哲宇對壞版的明確批評（「太批判、切入點不對、會炎上……」「不要公審人家的私生活」），是標籤最乾淨的候選。

追出處後，兩組的壞版都不在 git 裡。金曲獎 v1 是放在 `reports/article-evolve/` 的暫存稿，收官時刪掉，從沒 commit；彎彎被糾正的那份稿也是寫到一半就刪掉重來。git 裡唯一以外遇為主軸的彎彎全文是投稿者另一份原版，不同作者、不同輪，拿來替代就是硬湊。所以補充題沒有跑，查核紀錄在 [`SUPPLEMENT-PROVENANCE.md`](evaluation/grader-pilot-2026-10/SUPPLEMENT-PROVENANCE.md)。

這不影響主判讀。就算兩組都能跑、兩位分身都選對，五對口徑下也最多 3／5，到不了「選對 ≥ 4」。它影響的是下一次怎麼做：母報告更正後的五對計分題裡，從 git 拿得到兩版完整正文的只有施振榮、影視配樂、魏如萱三對，其餘兩對都要哲宇介入（指定新配對，或接受重寫出來的壞版）。兩組沒留下來的原因是同一個流程習慣：退稿的草稿在收官時刪掉，git 只留改好的那一版。
